# Бакыт · OPS

Операционная платформа для управления несколькими бизнесами: магазины в аэропортах (B2C) и общежитие для студентов.

## Модули

- **Магазины** — склад (остатки, приход/списание), продажи по товарным позициям, табель сотрудников
- **Общежитие** — реестр жильцов, договоры аренды, оплаты
- **СЭД** — документы с маршрутом согласования (аналог Documentolog, MVP)
- **Сотрудники** — общий справочник по всем точкам

## Статус

Фронтенд-прототип. Данные хранятся в `localStorage` браузера — бэкенда и базы данных пока нет.
Продажи вносятся вручную (без интеграции с кассой/эквайрингом). ИИН проверяется по контрольной сумме локально — без обращения к ГБДФЛ. Подписание документов в СЭД — симуляция маршрута согласования, без реальной ЭЦП.

## Стек

React 18 + Vite

## Запуск локально

```bash
npm install
npm run dev
```

## Сборка

```bash
npm run build
npm run preview
```

## Деплой

Проект готов к деплою на Vercel — просто импортируйте репозиторий, фреймворк (Vite) определится автоматически.
